| Path | Status | Purpose |

## OTB site autoresearch

Use `site/<area-slug>/` only for OTB USA landing work.

Recommended area slugs:

- `hero`
- `audience`
- `programa`
- `boston-harvard`
- `speakers`
- `investimento`
- `faq`
- `whatsapp-cta`
- `seo`

All OTB site runs must respect:

- Product/source copy in `src/content/products/otb.json`.
- WhatsApp messages starting with `Olá, Laura!`.
- Harvard references as contextual only, never affiliation/endorsement/certification.
- OTB Navy/Gold design canon.
- Bun-only validation.

Historical non-OTB runs are archived under `_archive/legacy-site/` and are not active references.
