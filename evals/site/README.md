# OTB USA site evals

Active area for future OTB USA landing-page autoresearch runs.

Create one folder per area slug, for example:

```text
site/hero/runs/YYYY-MM-DD-<run-id>/
site/investimento/runs/YYYY-MM-DD-<run-id>/
site/seo/runs/YYYY-MM-DD-<run-id>/
```

Do not copy historical runs from `_archive/legacy-site/` into active OTB evals unless they are rewritten for the OTB product, audience, CTA, legal guardrails, and design canon.
