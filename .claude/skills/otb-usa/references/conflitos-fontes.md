# OTB USA — conflitos entre fontes

## Regra principal

Quando fontes divergirem, não mesclar fatos silenciosamente. Sinalize o conflito e peça confirmação para dados operacionais que afetem promessa, preço, data, local, certificação, contato ou URL.

## Fonte canônica atual do repo

- Copy publicada: `src/content/products/otb.json`.
- Schema: `src/content.config.ts`.
- URL canônica usada nos docs/config: `https://otb.drasacha.com.br`.
- Local/copy internacional atual: Boston/EUA e ecossistema acadêmico de Harvard.

## Guardrails

- URLs ou destinos legados não são fonte se não estiverem alinhados ao OTB USA atual.
- Qualquer alteração de preço, data, carga horária ou destino internacional precisa de confirmação.
- Harvard deve ser tratado apenas como contexto geográfico/institucional, sem vínculo oficial.

## Decisão segura em caso de dúvida

1. Manter a versão de `src/content/products/otb.json`.
2. Evitar afirmação nova.
3. Direcionar para WhatsApp/SDR quando a decisão for comercial.
4. Registrar a dúvida no plano ou resposta final.
